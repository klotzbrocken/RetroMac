NeXTSTEP

NeXTSTEP

NeXT, Inc. · 1.0 released September 1989

After leaving Apple in 1985, Steve Jobs founded NeXT to build a workstation for higher education. NeXTSTEP was its operating system: a Unix core (the Mach microkernel over BSD) wrapped in the most advanced object-oriented desktop of its era, drawn on screen with Display PostScript in a crisp four-grey palette.

Its development tools — Interface Builder and Project Builder, written in Objective‑C against the AppKit framework — let a small team assemble real applications by dragging objects together. That toolchain is the direct ancestor of today's Xcode and Cocoa.

What made it special

  • The Dock, the vertical application menu and the Workspace file viewer — the layout this theme recreates — all debuted here.
  • Ran on the NeXT Computer, a one-foot magnesium cube ($6,500), and later the cheaper NeXTstation "slab".
  • Fully object-oriented, network-transparent, with a printing model identical to the screen — what you saw is what you got.
  • OpenStep (1994, with Sun) opened the frameworks; GNUstep and NEXTSPACE keep them alive today.

ⓘ  Did you know…

The World Wide Web was born on a NeXT. Tim Berners-Lee wrote the first browser and web server on a NeXT Computer at CERN in 1990. He taped a hand-written label on it:
"This machine is a server. DO NOT POWER IT DOWN!!"
Doom and Quake were built on NeXT. id Software developed both landmark games on NeXTSTEP workstations before shipping them to DOS.
You use NeXTSTEP every day. Apple bought NeXT in 1997, bringing Jobs back; NeXTSTEP became the foundation of Mac OS X, and so of macOS and iOS. That is why Apple's frameworks are still full of classes prefixed NS — for NeXTSTEP (NSString, NSObject, …).
