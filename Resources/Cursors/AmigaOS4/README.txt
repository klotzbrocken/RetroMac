AmigaOS 4 pointer set
=====================
"lvl.pointers_AOS4" v1.1 by levellord (2022), the 20 px Red set, from
https://www.amiga-look.org/node/782 — licensed under Creative Commons
Attribution-ShareAlike 4.0 International (https://creativecommons.org/licenses/by-sa/4.0/).
The author gives it without warranty.

Changed for RetroMac: each pointer's PNG (stored in the archive as an AmigaOS 4 .info) is
doubled in size, pixel for pixel, for Retina density; the hotspots come from the pointers'
own XOFFSET/YOFFSET. Converted by Scripts/amiga-pointers.swift. Under the same licence.

A modern set made for AmigaOS 4.1 (loosely based on DMZ-White and Quintom), not the pointer
of the 2008 release, of which no picture is to hand.
