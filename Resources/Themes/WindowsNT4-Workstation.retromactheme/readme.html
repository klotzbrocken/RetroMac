Windows NT 4.0

Workstation · Microsoft · Build 1381 · July 1996

Windows NT 4.0 put the Windows 95 desktop on top of Microsoft’s fully 32-bit, protected-memory NT kernel: the Start button, the taskbar and the grey 3D chrome, but with user accounts, NTFS and a system that one crashing program could not take down.

This theme follows the original English Workstation release, Build 1381, with the Explorer shell it shipped with — before Internet Explorer 4’s Desktop Update.

In this theme

  • The desktop of a fresh install: My Computer, Network Neighborhood, Inbox, Internet Explorer, Recycle Bin and My Briefcase.
  • The Start menu with NT’s program groups. Administrative Tools open the Mac’s own tools: Disk Administrator is Disk Utility, Event Viewer the Console, Performance Monitor the Activity Monitor, Windows NT Diagnostics the System Information.
  • Boot Phases on Firmware: an Award BIOS, the OS Loader with its menu, the blue kernel screen and NT’s start-up screen, then the desktop. Nothing asks for a password.
  • The wallpaper is a RetroMac adaptation on teal #058182 of a modern redraw of NT’s start-up artwork, its three typing errors corrected.

ⓘ  Did you know…

Workstation and Server. The same NT 4.0 came as Workstation for desks and Server for the back room; this theme is the Workstation, with its own Start menu banner.
Not a Windows 95. NT ran on Intel, Alpha, MIPS and PowerPC machines; the 95 look was new in 4.0, the kernel underneath dated back to 1993.
