Windows Me

Microsoft · Millennium Edition · 2000

Windows Me kept the familiar grey-and-blue Windows 98 desktop and layered on a more consumer, multimedia focus. It introduced System Restore, Windows Movie Maker and Windows Media Player 7, refreshed the Start menu with its "Windows Me / Millennium Edition" banner, and hid real-mode DOS to boot faster.

It was the last of the 9x/DOS consumer line before Windows XP unified the home and business worlds on the NT kernel.

What made it special

  • System Restore — roll the PC back to an earlier working day.
  • Windows Movie Maker and Media Player 7 for home video and music.
  • Refreshed shell: updated folders, My Network Places, and the Me Start banner.
  • Faster boot by hiding real-mode MS-DOS — the same 98 look under the hood.

ⓘ  Did you know…

The last of the line. Windows Me was the final release built on the MS-DOS/9x foundation — every consumer Windows after it runs on the NT kernel.
Movie Maker’s debut. Me was where Windows first shipped a built-in video editor, a decade before smartphones made everyone a filmmaker.
The safety net. System Restore’s "go back to yesterday" idea was novel enough that it outlived Me and survives in Windows to this day.
