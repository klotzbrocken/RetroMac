Windows 7

Microsoft · 2009

Windows 7 (2009) is the release that won people back after Vista. It kept the same modern core but made it fast and pleasant: the translucent Aero glass look, and a reinvented taskbar — the Superbar — where programs pinned, grouped and showed live thumbnail previews.

New window tricks like Aero Snap and Shake, jump lists and libraries made everyday work smoother, and it became one of the most loved and longest-used versions of Windows.

What made it special

  • Aero glass: translucent, glowing window chrome.
  • The Superbar taskbar with pinning and live thumbnails.
  • Aero Snap (drag a window to an edge to tile) and Shake.
  • Jump lists, libraries and the round Start orb.

ⓘ  Did you know…

“Vista, done right.” 7 shared Vista's foundations but fixed the speed and the rough edges, and the reception flipped from frustration to affection.
Snap started here. Dragging a window to the screen edge to half-tile it — a gesture people now use everywhere — debuted as Aero Snap.
Hard to say goodbye. Windows 7 stayed so popular that many held onto it right up to the end of support in 2020.
