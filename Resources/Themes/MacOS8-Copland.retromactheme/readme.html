Mac OS 8 (Copland)

Apple · developer release D11E4 · June 1996

Copland was the Mac OS that never shipped: the modern system Apple worked on from 1994, with a new kernel, protected memory and preemptive multitasking, to be released as Mac OS 8. In June 1996 developers received build D11E4; two months later Apple stopped the project and went looking for an operating system to buy, and found NeXT. This theme is that developer release, rebuilt from its own files: the Purple desktop, the lavender folders and the grey Platinum windows that Mac OS 8 inherited a year later.

What made it special

  • Themes: the Appearance Manager drew every window and control from data in a theme file. D11E4 shipped two, “Default Theme” and “Z Theme”.
  • Platinum appeared here first: grey windows with fine stripes, bevelled buttons, the look Mac OS 8 kept in 1997.
  • The desktop pattern, the icons and the patterns offered under Settings › Desktop are D11E4's own, decoded from its resource forks.

ⓘ  Did you know…

“Find is disabled because it is not scheduled to appear in DR1.” D11E4 told developers so in a dialog, and pointed them to an extension library that turned it on anyway.
The Finder had a menu called “Spaz”, between View and Help: a debugging menu nobody outside Apple was meant to see.
