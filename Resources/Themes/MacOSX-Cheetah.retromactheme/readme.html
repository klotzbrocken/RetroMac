Mac OS X

Apple · 10.0 “Cheetah”, March 2001

Mac OS X 10.0 — internally “Cheetah” — shipped in March 2001 and started everything modern about the Mac. It introduced Aqua: glossy pinstripes, a pulsing blue default button, translucent menus, the Genie minimise effect and the magnifying Dock.

Under the candy shell it was Unix: the Darwin core (BSD + the Mach kernel) inherited straight from NeXTSTEP, which Apple acquired in 1997.

What made it special

  • Aqua — glossy “lickable” buttons, pinstripes and the pulsing default button.
  • The magnifying Dock and the Genie minimise animation.
  • A real Unix foundation (Darwin) with protected memory and true multitasking.
  • The first of the big-cat release names.

ⓘ  Did you know…

Good enough to lick. Steve Jobs on Aqua's candy-coloured buttons:
“We made the buttons on the screen look so good you'll want to lick them.”
NeXT under the hood. OS X descends directly from NeXTSTEP — the Dock, the Cocoa frameworks and the “NS” class prefix all came along when Apple bought NeXT and Jobs returned.
Slow but pivotal. 10.0 crawled on 2001 hardware; a free 10.1 update later that year made it usable, and the line never looked back.
