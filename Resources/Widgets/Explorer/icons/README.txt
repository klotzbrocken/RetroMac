Windows 2000 Professional shell icons for the Explorer's Windows 95-2000 look, each at 32 px
(Large Icons, the folder panel) and 16 px (List, Details, the title bar).

Source: the Windows 2000 icon set Maik supplied (.ico files); each PNG is the .ico's own frame at
that size, at its highest colour depth, with the icon's mask as alpha. Nothing is resampled.
mydocs-32.png is the 48 px frame of Documents.ico cropped to its 32 px drawing, because the
.ico's 32 px frame draws the folder smaller than the shell showed it.
