Windows 95

Microsoft · 24 August 1995

Windows 95 is the release that set the shape of the desktop for the next 25 years: the Start button, the taskbar, the Recycle Bin, and windows with the grey 3D chrome and solid navy title bars. It fused MS-DOS and a 32-bit, pre-emptively multitasking shell into one consumer system.

It also brought Plug and Play, long file names (goodbye 8.3), and a launch so big it turned an operating system into a pop-culture event.

What made it special

  • The Start menu and taskbar — the template every desktop still follows.
  • Plug and Play hardware and long file names.
  • A 32-bit shell over MS-DOS, with the Recycle Bin and My Computer.
  • Grey 3D window chrome with solid navy title bars.

ⓘ  Did you know…

The midnight launch. On 24 August 1995 people queued outside shops at midnight to buy an operating system — something that had never really happened before.
A rock anthem for a Start button. Microsoft licensed The Rolling Stones’ “Start Me Up” for the launch campaign, built around the brand-new Start button.
Hidden on the CD. The Windows 95 CD-ROM tucked a “Fun Stuff” folder onto the disc — music tracks and the Weezer “Buddy Holly” music video.
