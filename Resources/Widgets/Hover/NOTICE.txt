Hover! — bundled with RetroMac (Windows 95 theme, "Fun Stuff (D:)" CD-ROM)
==========================================================================

Hover! is a game created by Microsoft Corporation, originally shipped on the
Windows 95 CD-ROM in 1995. The files in this directory are the HTML5 remake
that Microsoft published at http://hover.ie/ in 2013.

    Hover! (c) 1995, 2013 Microsoft Corporation.

The game is included in RetroMac as a fan tribute for personal, non-commercial
use, to recreate the contents of the original Windows 95 "Fun Stuff" folder.
RetroMac is not affiliated with, sponsored by, or endorsed by Microsoft.
Microsoft, Windows and Hover! are trademarks of Microsoft Corporation.

Modifications made for RetroMac
-------------------------------
  * Asset paths rewritten from absolute to relative so the game runs from a
    local file:// URL with no web server.
  * The external Internet Explorer promo flyout was removed and replaced with
    an inert stub in index.html.
  * All @font-face rules pointing at hover.ie and i.s-microsoft.com were
    removed and the font stacks replaced with locally available faces, so the
    game makes no network requests.
  * The "Fun Stuff" header button's link to a Microsoft OneDrive shortlink
    (sdrv.ms) was removed for the same reason.
  * Only the single-player "classic" (?retro) mode is reachable from RetroMac.
    The multiplayer, scoreboard and social-sharing code paths are unused.
