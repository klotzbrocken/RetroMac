Windows 3.1

Microsoft · 1992

Windows 3.1 (1992) is the release that made Windows mainstream. It ran on top of DOS and organised everything through Program Manager and File Manager, with grey 3D buttons, the teal (#008080) desktop and, for the first time, scalable TrueType fonts.

It wasn't a full operating system on its own — DOS did the real work underneath — but it put a friendly, mouse-driven face on the PC for millions of people.

What made it special

  • Program Manager and File Manager, the DOS-era desktop.
  • TrueType fonts arrived, so text scaled cleanly.
  • The unmistakable teal desktop and grey 3D chrome.
  • Solitaire and Minesweeper shipped in the box.

ⓘ  Did you know…

Solitaire had a job. Microsoft bundled Solitaire not just for fun but to teach a generation the mouse — dragging cards taught click-and-drag.
Not really an OS. Windows 3.x was a graphical shell running on top of MS-DOS, which still handled files and hardware underneath.
That teal. The default #008080 desktop is burned into the memory of everyone who used a PC in the early '90s.
